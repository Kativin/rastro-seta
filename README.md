# 🍄 Rastro Seta

App web (PWA) para salir a buscar setas: muestra el mapa donde estás, sombrea por dónde has pasado (círculo de 3 m de diámetro) y permite marcar dónde has cogido setas.

## Instalar en el móvil
- **Android (Chrome):** abre la web → menú ⋮ → *Añadir a pantalla de inicio* / *Instalar app*.
- **iPhone (Safari):** abre la web → botón Compartir → *Añadir a pantalla de inicio*.

## Publicar una nueva versión
1. Cambia los archivos que quieras.
2. Sube el número de `VERSION` en `sw.js` (p. ej. `rastro-seta-v2`).
3. Haz commit y push. Los móviles se actualizan solos al abrir la app.

Los datos (rastro y setas) se guardan en el propio móvil; usa *⋯ → Exportar* para hacer copia.
